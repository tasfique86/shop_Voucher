# Application Commands

Here is a quick reference for the commands you need to run and build your application.

| Action          | Command       | Description        |
| :-------------- | :------------ | :----------------- |
| **Run Web App** | `npm run dev` | Runs the React web |

app in the browser for quick development. |
| **Run Desktop App** | `npm run electron:start` | Runs

the app as an Electron desktop window for testing. |
| **Build Installer (.exe)** | `npm run dist-win` | Packages the app into an installable `.exe` file for Windows. |
| **Build Directory (No Installer)** | `npm run package-win` | Builds the Windows app executable inside a folder. |
